## Lesson

An **angle** measures an amount of turn. A full turn is 360°, the "360" of a skateboard trick. A half turn, a "180", is 180°.

**Angles on a straight line add up to 180°**, because a straight line is a half turn.

![](figures/line.svg){width=40%}

$130^\circ + ? = 180^\circ$, so the missing angle is $50^\circ$.

**Angles around a point add up to 360°**, because going all the way round is a full turn.

![](figures/point.svg){width=32%}

$90^\circ + 150^\circ + ? = 360^\circ$, so the missing angle is $120^\circ$.

**Method:** add up the angles you know, then subtract from 180° (a line) or 360° (a point).
